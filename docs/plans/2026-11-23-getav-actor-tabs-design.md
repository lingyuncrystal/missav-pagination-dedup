# GetAV 演员卡片双 Tab 设计

日期：2026-11-23

## 目标

在 GetAV 影片详情页的演员卡片内增加“简介 / 影片介绍”两个 Tab。默认保留并显示原演员简介；演员卡片接近视口时预加载 7mmtv 影片介绍，点击第二个 Tab 后展示文字和原比例图片。

## 交互与视觉

- 默认选中“简介”，原演员卡片内容不复制、不移动，避免破坏 React 节点引用。
- Tab 栏作为演员卡片的新子节点插入，采用与 GetAV 深色界面一致的克制型设计：低对比边框、玫红激活线、清晰的键盘焦点状态。
- 两个按钮在手机上等宽并排；使用 `role="tablist"`、`role="tab"`、`aria-selected` 和 `aria-controls`。
- “影片介绍”面板初始隐藏。演员卡片进入视口前约 300px 时预加载；加载中、空结果、失败和重试均在面板内部反馈。
- 切回“简介”只恢复原内容显示，不取消已完成请求；本页内再次切换不重复请求。

## 技术边界

- 仅匹配 GetAV `/videos/<番号>` 详情路由，不影响列表卡片和订阅页。
- 复用现有 `load7mmtvIntro()`、`renderFilmIntro()`、中文优先/英文回退及内存缓存。
- GetAV 是 Next.js/React 页面：只插入独立 Tab 与介绍面板，并对原内容设置显示状态；不重排、不克隆、不替换原演员 DOM。
- 在现有水合门控后初始化；MutationObserver 处理客户端路由和卡片重新渲染，注入节点消失后可重新挂载。
- 演员卡片定位采用多信号：演员/女优标题文字、演员资料链接路径和含头像的局部卡片；若无法可靠定位则放弃注入，不冒险修改其他内容。

## 验证

- DOM 夹具覆盖详情路由识别、演员卡片定位、幂等挂载、Tab 切换、提前 300px 预加载、失败重试和 React 重渲染后恢复。
- 运行 Node 语法检查、ScriptCat 静态检查、既有 Jable/MissAV 回归和发布 dry-run。
- GetAV 当前在桌面调试环境不可直连，发布后由手机真站确认演员卡片位置、预加载和图片显示。
