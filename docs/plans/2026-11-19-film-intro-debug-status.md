# 研发状态：MissAV「影片介绍」Tab

日期：2026-11-25

## 当前研发版本

- 分支：`dev`
- 最新功能版本：`4.0.30-dev.30`
- 正式版 `main` 未修改
- 研发版地址：`https://raw.githubusercontent.com/lingyuncrystal/missav-pagination-dedup/dev/missav-enhancer.user.js`

## 已实现

- MissAV 详情页增加「影片介绍」Tab。
- 点击后按番号 POST 搜索 7mmtv，优先 `/zh/` 中文详情，失败回退 `/en/` 英文详情。
- 从 7mmtv `.video-introduction-images-text` 读取介绍文字。
- 从 `#fullvideo_showallcg img` 和 `fullvideo_showallcg_arr` 读取全部图片。
- 图片按 `width: 100%; height: auto` 展示，保持比例、不裁剪。
- 请求只在点击 Tab 后触发，并缓存当前页面结果。

## Chrome 真站调试结果（dev.20–dev.21）

- 测试页：`SONE-604`；ScriptCat 真实跨站请求成功取得 7mmtv 中文详情，解析到 268 字介绍和 13 张图片。
- 已定位「点击后内容没有显示」的根因：MissAV 详情页没有 `.tab-content`，旧逻辑将介绍面板追加到 `body` 末尾，导致内容出现在页脚之后。
- dev.20 将介绍面板插入原详情面板之后；真站注入验证面板位置、文字和图片显示均正常。
- 已验证「影片介绍 → 磁力下载 → 详情 → 影片介绍」完整切换：介绍和详情按需显示，磁力下载独占高亮，详情内容可恢复。
- 已验证快速切走时，介绍 Tab 的延迟视觉校正不会重新打开面板或残留高亮。
- dev.21 修复介绍文字继承为纯黑、与深色渐变背景冲突的问题；正文和来源链接改用与原详情一致的 `rgb(184, 186, 188)` 浅色。
- MissAV 详情页使用 Alpine.js，原始 Tab 状态由 `currentTab` 控制；页面世界调用和 DOM 显示/高亮兜底继续保留。
- dev.22 修复无语言前缀的详情页不安装“影片介绍”：详情 Tab 现优先按 Alpine 的 `video_details` 绑定识别，并以多语言标签文字兜底，不再只支持“详情”与 “Details”。
- dev.23 将同一套 7mmtv 影片介绍扩展到 Jable 详情页：卡片位于标签与评论反馈框之间，滚动临近时自动加载，失败时支持原位重试。
- dev.24 补充 Jable `/s数字/videos/<番号>/` 分片详情路径识别，`/s0/videos/miaa-711/` 等页面现在与普通 `/videos/` 页面使用同一影片介绍流程。
- dev.25 修复 Jable 详情主标题未进入标题增强链：将真站 `.header-left > h4` 无链接标题按当前番号收集，缓存命中与免费中文源结果现在会回写详情标题。
- dev.26 将影片介绍扩展到 GetAV 详情页演员卡片：卡片顶部增加“简介 / 影片介绍”双 Tab，原演员节点保持原位；临近视口前约 300px 预载 7mmtv 文字与图片，失败可重试，并在 React 重渲染后自动恢复。
- dev.27 修复 GetAV 列表返回时 URL 页码与 React 内容错位：列表页按排序、页码保存首屏番号快照，监听 `popstate` 与 bfcache `pageshow`；仅当当前内容签名与同页快照不一致时重新加载当前 URL。
- dev.28 将演员列表 `/stars` 纳入同一返回恢复；扩展 `getav.co`、`getav.live`、`getav.top`、`getav.me` 域名匹配；订阅页演员卡片从 `/stars/<id>` 详情 h1 读取中文名并缓存回写。
- dev.29 修正订阅页目标：改为处理 `/series/<id>` 系列卡片，从系列详情 h1 读取中文名称，并从 `og:image` 或详情首张图片补回系列封面。
- dev.30 将返回恢复扩展到 `/stars/<id>?page=<n>` 演员作品分页，例如 `/zh/stars/1476?page=2`。
